## Project Overview
HARIS (High Alert Recognition Intelligent System) is an AI-powered application designed to detect and analyze driver behaviors using both in-car and road cameras. By leveraging advanced computer vision techniques, HARIS intelligently processes real-time image data to identify critical driving behaviors. This innovative system aims to enhance road safety by providing timely alerts and insights into driver performance and potential hazards..

## Features
- **Real-time Monitoring:** Continuously monitors driving behavior using sensors and cameras.
- **Behavior Analysis:** Analyzes driving patterns to detect aggressive driving, drowsiness, and distractions.
- **Alert System:** Provides instant alerts to drivers to correct risky behaviors.
- **Data Visualization:** Offers comprehensive visualizations of driving data for analysis and reporting.
- **Mobile Integration:** Accessible via a mobile app for ease of use and monitoring on the go.

## Technologies Used
- **Programming Languages:** Python, JavaScript
- **Machine Learning Frameworks:** TensorFlow, Keras
- **Data Processing:** Pandas, NumPy
- **Web Development:** Django, Flask (Backend), React.js (Frontend)
- **Mobile Development:** React Native
- **Database:** PostgreSQL, MongoDB
- **Visualization:** Matplotlib, Seaborn
- **APIs:** OpenCV for image processing, various sensor APIs
